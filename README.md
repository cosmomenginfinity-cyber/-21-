# 第二十一届全国大学生智能汽车竞赛卡丁组国二源码及建模

大一参赛，半年多备赛，全国二等奖。这里记录的是我这一段智能车经历中留下的代码与机械设计，也希望能给后来参赛的同学提供一些参考。

## 项目概述

这是我在大一参加第二十一届全国大学生智能汽车竞赛卡丁组时积累的项目资料。备赛周期只有短暂的半年多，很多知识都是一边学、一边做、一边在车上验证。从底层驱动、闭环控制到路径记录、视觉跟随，再到机械结构的反复修改，这些文件保留了当时摸索和迭代的痕迹。

本仓库将同一参赛项目的两个代码工程和建模资料放在一起：`TLD7002_TC387_Demo` 是原本省赛科目一、科目二的整合工程；`subject3(speed)` 是国赛代码，包含科目三相关的视觉跟随、路径记录与返航等实现；`建模` 包含前后轮闭环齿轮设计及车辆配套结构模型。两个代码目录是不同阶段的独立工程，使用时按目标选择其中一个导入。

现在，我决定不再继续参加智能车比赛，因此把自己在这段经历中编写的代码、设计的模型和已有资料全部公开。它们未必是最优解，也还保留着赶工、调试和试错留下的不足，但希望这些真实的过程能让后来的人少走一点弯路。

## 仓库内容

| 目录 | 对应阶段 | 主要内容 |
| --- | --- | --- |
| [`TLD7002_TC387_Demo/`](TLD7002_TC387_Demo/) | 省赛科目一、科目二整合 | 路径记录与回放、惯导与编码器处理、前后轮闭环控制、科目二点位与语音控制相关模块、TLD7002 灯光驱动等 |
| [`subject3(speed)/`](subject3%28speed%29/) | 国赛代码 | 视觉跟随、路径记录与返航、车辆闭环控制，以及动作任务、停车任务和调参菜单等 |
| [`建模/`](%E5%BB%BA%E6%A8%A1/) | 机械结构与加工资料 | 前后轮闭环齿轮设计，以及前后轮固定件、摄像头支架、转向限位、遮光罩、防水件等；含 DWG、STL、3MF 与部分历史备份 |

两个代码工程中，`user/` 是各核心入口与中断相关文件，`code/` 主要存放业务逻辑，`libraries/` 为底层库与外设驱动，`.project`、`.cproject` 是工程配置。`Debug/`、`.ads/` 等目录保留了归档时的构建和调试资料。

## 赛题参考

赛题细节请查阅卓晴老师的文章：[《第21届智能车竞赛卡丁快跑组比赛科目细则》](https://zhuoqing.blog.csdn.net/article/details/154697989)。

该文介绍了以下科目：

- **科目一：自动驾驶。** 按规定方向绕行锥桶，并完成倒车入库。
- **科目二：战场救护（人车交互）。** 根据自然语言口令完成灯光、鸣笛、通过门洞和车模运动等任务。
- **科目三：如影随形（穿越迷宫）。** 先按规定路径完成引导阶段，再依据记录的路径自动返回；文章对国赛阶段提出了机器视觉跟随引导员的要求。

这里的科目介绍用于帮助理解代码背景。具体赛制、尺寸、评分及后续调整，以对应赛事通知和现场规则为准；本仓库的功能与菜单请结合实际源码阅读。

## 开发环境与硬件

- **控制平台：** 英飞凌 AURIX TC387 系列，工程编译配置使用 `tc38x`。
- **开发工具：** AURIX Development Studio（ADS）及工程所需的 TASKING 工具链。逐飞库文件头记录的参考开发环境为 ADS v1.9.20，实际导入时请核对本机工具链兼容性。
- **底层依赖：** 仓库内已带有逐飞 TC387 开源库和英飞凌底层库。
- **外设适配：** 按所选工程核对电机驱动、转向角反馈、编码器、IMU、IPS 屏幕、按键、遥控接收与灯光模块等。国赛视觉代码使用 SCC8660 摄像头相关接口。

这里归档的是嵌入式工程，需要对应硬件和开发环境；在普通电脑上下载后，不能直接作为桌面程序运行。

## 使用说明

### 1. 获取项目并选择工程

可通过 GitHub 的 **Code → Download ZIP** 下载，也可以使用 Git：

```bash
git clone https://github.com/cosmomenginfinity-cyber/-21-.git smart-car-kart
cd smart-car-kart
```

想了解省赛科目一、科目二的整合思路，先看 `TLD7002_TC387_Demo`；想了解国赛版本，先看 `subject3(speed)`；机械设计资料单独在 `建模` 中查看。

### 2. 在 ADS 中导入

1. 打开 ADS，通过 **File → Import → General → Existing Projects into Workspace** 导入所选工程目录。
2. 目录 `TLD7002_TC387_Demo` 的工程名是 `TLD7002_TC387_Demo`；目录 `subject3(speed)` 导入后显示的工程名是 **`subject3_speed`**。
3. 检查工程的包含路径、编译配置和构建输出目录。现有 `.cproject` 中仍保留了旧工程名 `Seekfree_TC387_Opensource_Library` 对应的构建路径；若导入后报路径不存在，应在工程属性中把构建目录调整为当前工程的 `Debug` 目录。
4. 检查烧录器、调试接口和 ELF 路径。现有 `.launch` 文件包含 **`TC389QP`** 的历史设备配置，请按实物芯片与调试器重新核对，避免直接照搬。
5. 完成配置后执行 **Clean / Build**，再使用适配的调试与烧录方式下载程序。已有 `Debug/` 产物仅作为归档资料，移植时请重新编译。

### 3. 核对硬件并完成标定

首次上车前，建议依次完成：

1. 对照所选工程的 `code/initialize.c`、引脚定义和驱动文件，核对接线、通信端口与外设型号。
2. 分别确认左右轮电机方向、编码器正负号，以及转向反馈方向和中位，避免闭环反馈方向接反。
3. 根据实际车轮与齿轮传动关系，重新核对 `encoder.c/.h` 中的里程换算和转向角比例；再调整 `PID.c/.h`、`motor.c` 及相关参数。
4. 上电初始化 IMU 时保持车体静止，完成零偏校准，再检查路径记录和返航相关功能。
5. 先架空车轮、低速检查驱动与反馈，再逐步进行落地测试。仓库参数对应原车，换用不同结构后需要重新标定。

### 4. 省赛整合工程的阅读与操作入口

入口为 `TLD7002_TC387_Demo/user/cpu0_main.c`，初始化在 `code/initialize.c`，菜单在 `code/menu.c`。

- 主菜单包含 `Subject 1 (INS)`、`Subject 2`、`Servo Center`。
- 科目一菜单提供路径录制、保存到 Flash、设定巡航速度、路径回放、读取和清除等入口。
- 科目二菜单提供点位记录、清除、打印与语音控制运行入口；相关实现集中在 `sub2_*`、语音与 TLD7002 驱动模块中。
- 网络或云端语音功能涉及的连接信息与服务配置，需要按自己的环境设置。

各入口是否启用，还取决于当前初始化和编译配置；请结合源码与外设状态检查。

### 5. 国赛工程的阅读与操作入口

从 `subject3(speed)/user/cpu0_main.c`、`code/initialize.c` 和 `code/menu.c` 开始阅读。

- `color_vision.c/.h`：图像处理、目标识别、视觉跟随与相关标定参数。
- `pathrecorder.c/.h`、`back_ins.c/.h`：路径记录、返航与相关状态控制。
- `encoder_motor_ctl.c/.h`、`PID.c/.h`、`motor.c`：车辆闭环与执行控制。
- `sub3_build_mode.h`：`SUB3_CAMERA_ONLY_MODE` 当前为 `0U`，即车辆功能构建；设为 `1U` 用于摄像头与屏幕单独调试，会跳过部分车辆闭环硬件初始化，不能把它当作完整行车模式。

当前主菜单包含 `Action Task`、`Parking Task`、`Remote Control`、`Static Vision`、`Servo Center` 和速度设置等项目，使用 `KEY1/KEY2` 选择、`KEY3` 进入。运行中退出或停止按对应界面提示操作。

进行视觉跟随前，先通过 `Static Vision` 检查画面与目标识别，再按实际光照和安装位置调整 `color_vision.h` 中的颜色阈值、字节顺序、标志物尺寸、相机几何和跟随距离等参数。更换目标标志物或摄像头安装位置后，需要重新标定。

### 6. 查看和使用建模文件

- **DWG：** 使用支持该格式的 CAD 软件查看和修改图纸。
- **STL：** 使用建模软件或切片软件查看网格、检查尺寸，再按实际材料与工艺生成加工文件。
- **3MF：** 使用兼容的软件检查模型、摆放及已有打印配置，特别是名称中含 `gcode` 的文件，先确认其内容和目标打印机。
- **BAK：** 保留的历史备份，优先从对应正式文件查看，再按需要比对版本。

前后轮闭环齿轮设计请与编码器、转向反馈装置和原车装配关系一起理解。齿轮传动比、传感器安装位置或机械尺寸改变后，软件中的比例和限位也要同步调整；不要仅凭文件名直接确定加工版本。

## 写给后来参赛的你

半年多的准备，并不足以让我把所有问题都想明白。调不稳的车、反复修改的参数、重新画过的零件，都是这段经历的一部分。最后留下的，不只是一个奖项，也是在遇到问题时愿意继续查、继续试的习惯。

如果你也刚上大一，或者正对着一辆怎么都跑不好的车发愁，希望这些代码和模型能帮到你一点。先让一个模块正常工作，再把下一个问题弄清楚；每一次定位到原因、每一次让车稳定多跑一段，都是进步。

我决定在这里结束自己的智能车参赛经历，但很高兴能把这些积累留给后来的人。愿你少一些无从下手，多一些亲手做成的快乐；也愿你在这条路上，找到值得一起坚持的人。祝调车顺利，比赛顺利，走得比我更远。
